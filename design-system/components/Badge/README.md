# Badge

Selo curto que marca prioridade, origem ou decisão, sempre com texto.

- `span.selo` + uma variante: `alta`, `media` (prioridade da falha), `auto` (verificação automática), `humana` (revisão humana), `aprovada`, `editada`, `descartada`, `pendente` (decisão sobre a sugestão da IA).
- Pílula (`radius-pill`), texto `badge` (12.8px 700); as cores com borda usam a cor do texto como contorno.
- O texto carrega o significado: "Prioridade alta", nunca só "Alta" pintado de vermelho.
- Até três selos lado a lado, nesta ordem: prioridade → origem → decisão.
