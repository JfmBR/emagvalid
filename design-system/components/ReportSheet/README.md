# ReportSheet

Prévia da página do relatório em PDF, como uma folha de papel.

- `article.folha` com `aria-label`: única peça com sombra (`shadow-sheet`) e raio `radius-sheet`; largura máxima 860px.
- `div.capa` (sobrelinha, nome do site, URL em mono, data; filete de 2px em `ink`) → `div.resumo` (cartões com número em `stat`) → tabela de falhas → revisão humana → `p.assina`.
- A assinatura sempre credita a conclusão à pessoa auditora; o AcessaWeb é "apoio".
- Antes da folha, um aviso `alerta` se houver orientações sem revisão.
