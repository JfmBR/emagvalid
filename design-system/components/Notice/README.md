# Notice

Aviso em linha, com ícone, para informação importante ou alerta.

- `div.aviso` (informativo: `accent-soft` com filete `accent`) ou `div.aviso alerta` (`media-bg` com filete `media`).
- Ícone SVG de 20px com `aria-hidden="true"` (assets: `Icones/info.svg`, `Icones/alerta.svg`); o texto sozinho tem que bastar.
- `role="note"` para informação fixa; `role="status"` quando aparece por causa de uma ação.
- Uso obrigatório: dizer que a nota não é certificação (RF09, RNF07).
