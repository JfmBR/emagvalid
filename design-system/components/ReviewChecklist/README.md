# ReviewChecklist

Lista de itens que a ferramenta não julga e a pessoa auditora marca como verificados.

- `ul.checks` > `li` > `label[for]` (a linha inteira é clicável, contorno `line`, raio `radius-control`) > `input[type=checkbox]` de 22px em `accent` + texto "**requisito** · pergunta" (ex.: "**1.4** · A ordem de leitura e de tabulação faz sentido?").
- Esses itens não entram na nota; diga isso acima da lista.
- Cada item é uma pergunta de sim ou não, em uma frase.
