# Marca

- `acessaweb-icone.svg` — ícone do app, copiado do cabeçalho do protótipo (28×28). Cores fixas: `accent` claro (#2D46B9) e branco. Na interface, use o SVG em linha do protótipo, que segue o tema (`var(--accent)`, `var(--accent-ink)`). Ao lado do nome, use `aria-hidden="true"`.
- `acessaweb-anel.svg` — anel duplo extraído em vetor do slide 1 do pitch (88 raios, degradê `sun-yellow` → `sun-orange` → `sun-red`). Proporção ≈ 1:1.9 (vertical). Só sobre `brand-navy`; não recolorir, girar, cortar ou usar sobre fundo claro. Decorativo: `alt=""`.
