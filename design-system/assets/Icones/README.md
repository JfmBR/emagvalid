# Ícones

Os dois ícones do protótipo, 20×20, traço de 2px, usados dentro de `Notice`.

- `info.svg` — círculo com "i". Tinta fixa #2D46B9 (`accent` claro); na interface, use em linha com `stroke="var(--accent)"`.
- `alerta.svg` — triângulo com "!". Tinta fixa #7A4F00 (`media` claro); na interface, `stroke="var(--media)"`.

Sempre `aria-hidden="true"`: o texto do aviso carrega o sentido.
